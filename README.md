
# Weezer Sorter V3
This is an updated version of the V2 [Weezer sorter](https://weezersorter.github.io), which is an updated version of the original [Weezer sorter](https://weezersorter.tumblr.com/), which was based on this [character sorter](https://github.com/execfera/charasort). I added the new Gold Album, and the SZNZ Vinyl Exclusives.
